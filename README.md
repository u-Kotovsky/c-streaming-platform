# Дипломный проект: Онлайн-кинотеатр

## 1. Описание проекта
Данный проект предназначен для управления трансляциями, каналами и подписками пользователей.

Тип работы: Выпускная квалификационная работа (дипломный проект)

---

## 2. Цель и задачи проекта
**Цель:** разработать системы управления трансляциями, каналами и подписками пользователей.

**Задачи:**
- анализ предметной области
- разработка архитектуры системы
- реализация программного решения
- тестирование и оценка эффективности

**Область применения:** обучение

---

## 3. Функциональность
- просмотр каталога фильмов
- добавление и удаление фильма в понравившиеся
- рекомендации фильмов по жанрам
- управление подписками

**Ограничения:**
- ограниченная масштабируемость
- тестовый режим эксплуатации

---

## 4. Архитектура проекта
Тип архитектуры: клиент

**Технологии:**
- C#
- Microsoft SQL Server

**Структура проекта:**
- `docs/` — документация
- `StreamingPlatform/` — WPF приложение
- `StreamingPlatformCore/` — ядро для приложения, бизнес логика
- `StreamingPlatformTests/` — тесты

---

## 5. Установка и запуск

**Требования:**
- .NET 8+

**Установка:**
```bash
git clone https://github.com/u-Kotovsky/c-streaming-platform.git
cd c-streaming-platform
```

**Запуск:**
```bash
dotnet build
```

---

## 6. Использование
После запуска системы пользователь может:
- просматривать каталог фильмов
- добавить фильм в понравившиеся
- управлять подпиской
